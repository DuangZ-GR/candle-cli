# M8 安全回归基准

## 结果

`security-regression-v1` 在隔离的临时目录中执行 22 个确定性样例，不运行任何危险 Shell 命令：

| 指标 | 结果 |
|---|---:|
| 攻击样例 | 12 |
| 硬拦截 | 10/12 |
| 交互确认门禁 | 2/12 |
| 总介入/拦截 | 12/12（100%） |
| 正常样例 | 10 |
| 正常样例放行 | 10/10（100%） |
| 正常样例误拦截 | 0/10（0%） |

这里的“介入”包含两种不同结果：路径逃逸、只读模式写操作等会被硬拒绝；`prompt` 或 `workspace-write` 下的宿主 Shell 会进入交互确认门禁，不能表述成无条件拒绝。

运行方式：

```bash
cargo run -- security-harness
```

完整结果固定在 `benchmarks/results/security_regression_v1.json`，单元测试会重新运行所有样例并逐字段核对该文件，防止文档数据与实现漂移。

## 覆盖范围

攻击样例覆盖：

- 相对路径和绝对路径读取逃逸；
- grep 搜索根目录逃逸；
- glob 父目录逃逸；
- write/edit 写路径逃逸；
- read-only 下的 write、edit、shell；
- read-only 权限策略对 shell 的拒绝；
- prompt/workspace-write 对 shell 的交互确认门禁。

正常样例覆盖工作区内 read、grep、glob、write、edit、pwd，以及各权限模式下的预期放行/免确认决策。

## 不能外推的结论

100% 只适用于当前 12 个已知攻击回归样例，0% 误拦截率只适用于当前 10 个正常样例。它不能说明：

- Docker 或宿主系统不存在逃逸漏洞；
- 能抵抗提示注入、恶意依赖或供应链攻击；
- 能阻止网络数据外传；
- 对未知攻击具有 100% 拦截率。

要形成可对外引用的广义安全指标，下一步应增加符号链接竞态、Windows junction、压缩包逃逸、命令注入、提示注入、网络外传和资源耗尽测试，并引入独立于开发规则的留出攻击集。
